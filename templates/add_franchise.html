Franchise Creation Process

When you create a new franchise:

  • The franchise account will be created with is_franchise = True and is_active = False
  • No password will be set during creation
  • An activation email will be sent to the franchise with a link to set their password
  • After activation, the franchise must complete their profile before accessing the dashboard
